🚀 Workshop JavaScript — Solutions

Bienvenue dans mon repository dédié aux solutions des exercices du Workshop JavaScript – Parcours SAS.

L'objectif de ce repository est de pratiquer les bases de JavaScript à travers différents exercices progressifs, allant des variables jusqu'aux algorithmes de recherche et de tri, puis de mettre en pratique les connaissances acquises à travers deux mini-projets.

🌐 Workshop : https://workshop-java-script-sas.vercel.app/

📚 Contenu du workshop

Le workshop est composé de 11 étapes, suivies de 2 mini-projets :

| Étape | Thème |
|-------:|-------|
| 01 | Variables & Types |
| 02 | Opérateurs |
| 03 | Conditions |
| 04 | Conditions avancées |
| 05 | Boucles |
| 06 | Boucles avancées |
| 07 | Fonctions |
| 08 | Chaînes |
| 09 | Tableaux |
| 10 | Objets |
| 11 | Recherche & Tri |
| ⚑ | Mini-projet Stock |
| ⚑ | Mini-projet Contacts |
